## 📝 使用示例

### 注册
```bash
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "newuser",
    "password": "password123",
    "email": "user@example.com",
    "realName": "张三"
  }'
```

### 登录
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "admin123"
  }'
```

### 访问受保护接口
```bash
curl -X GET http://localhost:3000/api/auth/profile \
  -H "Authorization: Bearer <your_token>"
```

### 使用权限中间件
```javascript
const { authenticate } = require('./middlewares/auth');
const { hasRole, hasPermission } = require('./middlewares/permission');

// 需要登录
router.get('/profile', authenticate, controller.getProfile);

// 需要管理员角色
router.get('/admin', authenticate, hasRole('admin'), controller.adminOnly);

// 需要特定权限
router.post('/users', authenticate, hasPermission('user:create'), controller.createUser);

// 需要多个角色之一
router.get('/manage', authenticate, hasRole('admin', 'manager'), controller.manage);
```
